# Cybersecurity Awareness & Phishing Simulation Dashboard

## Project Overview

This project transforms raw data from phishing simulation campaigns into an interactive dashboard that provides a clear view of employees’ security behavior and risk levels.

Using visual perception principles, decluttering, and strategic use of color, the dashboard provides actionable insights that help executive management:

- **Identify Gaps:** Detect the departments with the highest security risk.
- **Support Decision-Making:** Direct security awareness and training efforts toward the departments that need them most.
- **Measure Maturity:** Track the development of the human first line of defense through behavioral and security reporting indicators.

## Dataset
The dataset used in this project was obtained from Kaggle and contains Google Reviews data used for analysis and visualization.

## How to Run the Project 

1. **Download Files:**
   - Download the project notebook (`.ipynb`) and the raw dataset (`.csv`) from this repository.
2. **Open in Colab:**
   - Go to [Google Colab](https://colab.research.google.com/), click **Upload**, and select the downloaded notebook (`.ipynb`).
3. **Upload Dataset:**
   - In Colab, click the **Files** 📁 icon in the left sidebar and upload the dataset (`.csv`).
4. **Run:**
   - Run the cells (`Runtime` > `Run all`).
